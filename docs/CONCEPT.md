# Концепція програми аналізу аварійних осцилограм COMTRADE

Статус: проєкт концепції, редакція 1 (2026-10-06). Підлягає підтвердженню замовником.

## 1. Призначення

Браузерний застосунок для інженерів РЗА. Задачі:

1. Аналіз роботи дистанційного захисту (ДЗ): годографи векторів опору на площині R-X з характеристиками зон.
2. Визначення виду КЗ та місця пошкодження (ОМП).
3. Формування звіту «Опис роботи пристроїв РЗА».

## 2. Платформа та обмеження

| Параметр | Рішення |
|---|---|
| Тип | Веб-застосунок, працює в браузері без сервера |
| Обробка даних | Лише локально в браузері; файли не передаються в мережу |
| Стек (пропозиція) | TypeScript + Vite; графіки — Plotly.js або uPlot; DOCX — бібліотека `docx` |
| Розгортання | Статичні файли (GitHub Pages або локальна папка) |
| Номінальна частота | 50 Гц за замовчуванням, з CFG; ручне перевизначення |

## 3. Вхідні дані

### 3.1 Формати

| Формат | Склад | Етап |
|---|---|---|
| IEEE C37.111-1991 / 1999 | CFG + DAT (ASCII, BINARY) | 1 |
| IEC 60255-24:2013 | CFG + DAT (ASCII, BINARY, BINARY32, FLOAT32), HDR, INF | 1 |
| «Регіна» | ava*.dat + RgSet.dat | 3 (після отримання зразків) |

Кодування CFG: автовизначення UTF-8 / cp1251 (термінали ЕКРА, Радіус, реєстратори Парма, Бреслер).

### 3.2 Джерела

Термінали РЗА (ABB, Siemens, NR, GE), вітчизняні/СНД термінали (ЕКРА, Радіус), реєстратори (Регіна, Парма, Бреслер). Реєстратор може містити кілька приєднань в одному файлі.

### 3.3 Співставлення каналів

- Автопідбір за назвою каналу, полем `ph`, одиницями (`V`/`kV`/`A`/`kA`).
- Ручне коригування призначень: Ua, Ub, Uc, 3U0, Ia, Ib, Ic, 3I0 для кожного приєднання.
- Інверсія полярності каналу.
- Збереження шаблону призначень для типу реєстратора/термінала (ключ — `station_name`, `rec_dev_id`).

## 4. Обчислення

### 4.1 Вектори (лічильники)

| Фільтр | Призначення |
|---|---|
| ДПФ, вікно 1 період (за замовчуванням) | Основний режим |
| ДПФ, вікно ½ періоду | Наближення до швидкодіючих алгоритмів |
| Косинусний фільтр | Придушення аперіодичної складової |
| Mimic-фільтр + ДПФ | Придушення аперіодичної складової з заданою τ |

Передискретизація при нерівномірній частоті дискретизації (кілька `samp` у CFG).

### 4.2 Петлі опору

- Міжфазні: Z_AB, Z_BC, Z_CA.
- Фаза-земля: Z_AN, Z_BN, Z_CN з компенсацією k0 у двох формах: |k0|∠φ або RE/RL, XE/XL.
- Опційно: компенсація взаємоіндукції паралельної ПЛ (k0m, струм 3I0 паралельної лінії).
- Вибір відображуваних петель.

### 4.3 Вид КЗ

Автоматичне визначення за симетричними складовими та співвідношенням фазних струмів і напруг: K(1), K(2), K(1,1), K(3); пошкоджені фази; напрямок (прямий/зворотний) за кутом I2/U2 та I1/U1 (аварійні складові). Результат — з наведенням критеріїв, за якими зроблено висновок.

### 4.4 ОМП

| Метод | Вхідні дані | Етап |
|---|---|---|
| Односторонній реактансний | Один файл | 2 |
| Односторонній Takagi | Один файл, доаварійний режим | 2 |
| Неоднорідна ПЛ (ділянки ПЛ/КЛ з різними Z1, Z0) | Один файл + довідник ділянок | 2 |
| Двосторонній | Два файли з обох кінців, синхронізація за моментом КЗ | 3 |

Результат: відстань у км від шин підстанції, номер ділянки, перехідний опір Rf.

## 5. Візуалізація

### 5.1 Осцилограми

- Миттєві значення та діючі значення (RMS основної гармоніки) обраних каналів.
- Дискретні сигнали з хронологією змін стану.
- Два курсори (доаварійний / аварійний момент), Δt між ними, масштабування.

### 5.2 Векторні діаграми

- Фазні U/I в момент курсора, вибір опорного вектора (напр. Ua = 0°).
- Лінійні напруги та струми петель (Uab, Ia−Ib тощо).
- Симетричні складові U1, U2, U0, I1, I2, I0: діаграма + таблиця.
- Порівняння доаварійний/аварійний на одній діаграмі, аварійні складові (Δ).
- Оновлення діаграми під час переміщення курсора.

### 5.3 Годограф опору

- Траєкторія Z(t) обраних петель на площині R-X з маркерами часу.
- Лінія імпедансу ПЛ.
- Характеристики зон:
  - універсальний полігон (X, R ф-ф, R ф-з, кут лінії, нахил верхньої межі, напрямленість);
  - колові (mho, зміщене коло);
  - шаблони терміналів: ABB REL670 (ZMQPDIS/ZMFPDIS), Siemens SIPROTEC 7SA, NR PCS-902/PCS-931 — з іменами уставок виробника.
- Визначення моменту входу траєкторії в кожну зону.

### 5.4 Одиниці

Перемикання первинні/вторинні величини з урахуванням поля P/S та коефіцієнтів primary/secondary з CFG. Годограф будується в тих самих одиницях, що й уставки термінала.

## 6. Довідник приєднань і проєкт

- Довідник приєднань: Z1, Z0 (Ом/км), довжина, ділянки, КТС, КТН, k0, k0m, уставки зон, тип термінала.
- Зберігання в браузері + імпорт/експорт JSON для обміну.
- Файл проєкту аналізу: посилання на осцилограми, призначення каналів, положення курсорів, обрані петлі, результати.

## 7. Звіт

- Формат: DOCX (редагований) + друк/PDF з браузера.
- Склад: загальні дані (об'єкт, приєднання, дата/час, джерело), вид КЗ, таблиця значень до/під час КЗ, хронологія дискретних сигналів, ОМП, рисунки осцилограм, векторних діаграм, годографів, висновок щодо дії ДЗ.

## 8. Етапи розробки

| Етап | Склад | Критерій приймання |
|---|---|---|
| 1 (MVP) | Парсер COMTRADE 1991/1999/2013; співставлення каналів; осцилограми; фільтри; ВД; 6 петель Z; годограф; універсальний полігон і mho; первинні/вторинні | Контрольні синтетичні КЗ: похибка |Z| ≤ 1 %, кута ≤ 1° у сталому режимі |
| 2 | Вид КЗ; ОМП односторонній (реактансний, Takagi, ділянки); довідник приєднань; звіт DOCX/PDF | Похибка ОМП на синтетичних даних ≤ 2 % довжини при Rf = 0 |
| 3 | «Регіна»; шаблони REL670, 7SA, PCS-902/931; двосторонній ОМП; k0m | Збіг результатів на реальних осцилограмах замовника |

## 9. Верифікація

- Генератор синтетичних COMTRADE з відомими параметрами КЗ (вид, відстань, Rf, аперіодична складова) — автоматичні тести обчислень.
- Реальні осцилограми замовника (додаються до репозиторію у `samples/`) — тести парсерів і регресійні перевірки.

## 10. Відкриті питання

1. Зразки файлів «Регіна» та, за наявності, опис структури ava*.dat / RgSet.dat.
2. Шаблон звіту (наявна форма «Опису роботи пристроїв РЗА» підприємства) — для відповідності структури DOCX.
3. Чи допустимо розміщувати реальні осцилограми у репозиторії (конфіденційність даних об'єктів).
