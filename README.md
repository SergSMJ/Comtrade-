# Аналізатор аварійних осцилограм

Браузерний застосунок для аналізу аварійних осцилограм COMTRADE та «Регіна»: осцилограми, векторні діаграми, годографи векторів опору з характеристиками зон дистанційного захисту.

Файли обробляються лише в браузері користувача й нікуди не передаються.

Концепція та етапи розробки: [docs/CONCEPT.md](docs/CONCEPT.md).

## Запуск

| Спосіб | Команди | Результат |
|---|---|---|
| Розробка | `npm install`, `npm run dev` | локальний сервер з автооновленням |
| Один файл | `npm install`, `npm run build:single` | `dist-single/index.html` — відкривається з диска без сервера, можна передати колегам |
| Статичний сайт | `npm install`, `npm run build` | `dist/` — для розміщення на вебсервері |

Перевірки: `npm test` (автотести обчислень і парсерів), `npm run typecheck`.

## Вхідні дані

| Формат | Файли |
|---|---|
| COMTRADE IEEE C37.111-1991/1999, IEC 60255-24:2013 | `.cfg` + `.dat` (ASCII, BINARY, BINARY32, FLOAT32); `.hdr` ABB 670 — еталонні значення для звірки |
| «Регіна» | `ava*.dat` разом з `RgSet.dat` |
| Характеристики зон | `.rio` (OMICRON) |
| Проєкт | `.json`, збережений цією програмою |

Файли перетягуються у вікно або обираються кнопкою «Відкрити файли…» (кілька одночасно).

## Робота

1. **Дані** — відомості про запис; автоматичне співставлення каналів з фазами приєднань, ручне коригування та інверсія полярності.
2. **Осцилограми** — миттєві та діючі значення, дискретні сигнали; курсор А (клік) і курсор В (Shift+клік).
3. **Векторні діаграми** — фазні та лінійні величини, симетричні складові, порівняння моментів А і В, аварійні складові.
4. **Годограф опору** — шість петель (AB, BC, CA, AN, BN, CN) на площині R-X, лінія Z1, зони ДЗ, момент першого входу в зону.
5. **Уставки** — параметри лінії, компенсація k0 (комплексна або RE/RL, XE/XL), взаємоіндукція паралельної лінії, зони (полігон, коло, REL670, 7SA, PCS-902/931), імпорт RIO, довідник приєднань.

Вибір фільтра (Фур'є 1 період, ½ періоду, косинусний, mimic) і перемикання первинних/вторинних величин — у верхній панелі.

## Методика

- Вектори — діючі значення основної гармоніки на каузальному вікні, що закінчується у відліку курсора. Кути всіх каналів відраховуються від єдиної опорної косинусоїди.
- Петлі фаза-земля — у площині прямої послідовності: `Z = Uф / (Iф + k0·3I0)`. Для режиму RE/RL, XE/XL R і X розв'язуються окремо.
- Характеристику REL670 для петель фаза-земля задано в петлевій площині, тому програма переводить її діленням на `(1 + k0)`.
- Перехід у вторинні Оми: `Zвт = Zперв · Kтс / Kтн`.

## Верифікація

Автотести (`tests/`):

- синтетичні КЗ A-N, B-C, C-N, ABC з відомими параметрами для всіх фільтрів, зокрема з аперіодичною складовою і через запис/читання COMTRADE. Похибка: |Z| ≤ 1 %, кут ≤ 1°;
- звірка з HDR термінала ABB REL670 (`samples/rel670`). Модулі збігаються в межах 1,5 %, різниці кутів — у межах 1°;
- масштаб «Регіни»: напруга шин 750 кВ у доаварійному режимі — 425–445 кВ фазної;
- полігони шаблону 7SA збігаються з RIO 7SA513 (`samples/siprotec`).

## Обмеження поточної версії (етап 1)

- Визначення виду КЗ, ОМП і звіт DOCX/PDF — етап 2.
- Шаблон PCS-902/931 побудовано за загальною структурою уставок. Кути органу напрямку та нахил реактивної межі потрібно звірити з інструкцією термінала (у формі вони позначені «*»).
- Структуру формату «Регіна» встановлено за файлами ХАЕС. Підписи дискретних входів RgSet не є доказом фактичного заведення сигналу.
